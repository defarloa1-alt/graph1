#vision
My original concept was that the sys would have a few core backbones - temporal, geographic, subject. temporal was set up as years, geographic based on a schema grounded in some authorities with geo-data for graphics, and subjects, which exist to enable agents to answer the question what is this? Library of congress and other categorizations surely have something to tether to. not everyclaim has temporal and geo aspects, but everything really does need a tie into an authoritive subject id, preferable a subject heirarchy - which might need to be a propritary, agent resolved categorization of subjects - since libraries can have a book repeated across shelves so someone picks one. We have the ability to do that though.
Wikidata is key. Wherever possible the system attempts to describe things through qid + properties + qualifers. Wiki is not authorative but it gives a good starting point, and the external ids of interest can be highly leveraged.
The use cases to remember is thus: 
    1. User asks for a full graph build of a polity like Roman Republic. We attempted this in legacy. From a commerical perspective these are packs, which can be subscribed or purchased on top of a core architecture which is domain independent and reusable.
    2. the user asks for a specific person, event, concept etc. 
         firstly a concierge agent (ultimitly in langraph i think) asks the question what is this? Do we have that subject in a repository or is a new subject needed.
Each subject normally can be seen from a different perspective - what we call facets.
That agents specialize in each facet in a certain period, event etc. They are instantiated, and during training propose claims and attempt to build propose a subgraph of that facet. The system persists their findings in the graphs, and the agents leverage it. They develop deep understanding of their facet, and are capable of coordination with other facets for cross facets analysis. They sleep after the subgraph is populated, waking periodically to check if there were any changes in their facet or another facet that has a relationship with it.
